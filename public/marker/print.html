Print at 100% / Actual size. พิมพ์ที่ 100% / ขนาดจริง (ปิด “พอดีหน้า”).

สื่อการเรียนรู้นี้ใช้สำหรับการฝึกกับหุ่นจำลองเท่านั้น ไม่ใช่เครื่องมือแนะนำตำแหน่งฉีดยาหรือการรักษาผู้ป่วยจริง
This educational tool is for mannequin-based simulation only. It is not intended to guide injection placement or treatment in real patients.

วิธีติดสติกเกอร์ / How to apply the sticker

  1. พิมพ์บนกระดาษสติกเกอร์ด้าน (ไม่มัน) แล้วติดบนแผ่นแข็งบาง ๆ (เช่น พลาสติก/การ์ดหนา ~1–2 มม.) ให้เรียบ
    Print on matte sticker paper and mount it on a thin rigid tile (plastic or thick card, ~1–2 mm) so it stays flat.
  2. ติดบนหลังมือของหุ่นมือขวา ให้กึ่งกลางอยู่เหนือข้อโคนนิ้วกลาง (MCP) และให้ลูกศรสีเหลือง TOP ชี้ไปทางปลายนิ้ว
    Fix it on the back (dorsum) of the right mannequin hand, centred over the middle-finger MCP knuckle, with the yellow TOP arrow pointing toward the fingertips.
  3. วัดความกว้างที่พิมพ์ได้จริงด้วยไม้บรรทัด แล้วใส่ค่าใน โหมดอาจารย์ → ปรับเทียบ → ความกว้างมาร์กเกอร์
    Measure the printed width with a ruler and enter it in Instructor Mode → Calibration → Printed marker width.
